## 1. Регистрация и вход

### Регистрация

1. Нажмите **«Войти»** в правом верхнем углу.
2. В открывшемся окне нажмите **«Зарегистрироваться»**.
3. Заполните поля:
   - Имя и фамилия
   - Имя пользователя (уникальное)
   - Email (уникальный)
   - Пароль
4. Нажмите **«Зарегистрироваться»** — вы будете автоматически перенаправлены на форму входа.

### Вход

1. Нажмите **«Войти»** в правом верхнем углу.
2. Введите email и пароль.
3. Нажмите **«Войти»**.

### Выход

- Нажмите **«Выйти»** в правом верхнем углу.

## 2. Поля коллекций

Поля — это базовые «кирпичики» данных. Сначала создаются поля, затем они добавляются к типам коллекций.

**Страница:** `/field-list` → **«Поля коллекций»** в навигации.

### Доступные типы полей

| Тип | Описание | Пример |
|-----|----------|--------|
| `string` | Текстовая строка | Страна, Производитель |
| `number` | Числовое значение | Год выпуска, Тираж |
| `date` | Дата | Дата покупки |
| `boolean` | Да/Нет | В наличии, Оригинал |
| `select` | Выбор из списка | Состояние: новое/хорошее/б/у |

### Создание поля

1. Перейдите в **«Поля коллекций»**.
2. Нажмите **«Добавить поле»**.
3. Заполните:
   - **Название** — как будет называться поле в таблице (например, «Год выпуска»)
   - **Описание** — пояснение к полю (необязательно)
   - **Тип** — выберите из списка выше
   - **Варианты** — только для типа `select`: введите варианты через запятую или по одному
4. Сохраните.

> Поле создаётся один раз и может использоваться в нескольких типах коллекций.

### Редактирование и удаление поля

- **Редактировать** — нажмите на карандаш рядом с полем.
- **Удалить** — нажмите на корзину. Удаление поля отвяжет его от всех типов коллекций, где оно используется.

## 3. Типы коллекций

Тип коллекции — это шаблон: он определяет структуру (набор полей), по которой вы будете собирать предметы.  
Например: «Монеты», «Марки», «Виниловые пластинки».

**Страница:** `/collection-type` → **«Типы коллекций»** в навигации.

### Создание типа коллекции

1. Перейдите в **«Типы коллекций»**.
2. Нажмите **«Создать тип»**.
3. Введите:
   - **Название** — например «Монеты СССР»
   - **Описание** — краткое пояснение
4. Сохраните.

### Добавление полей к типу

После создания типа нужно указать, какие поля он будет включать:

1. Откройте нужный тип коллекции.
2. Нажмите **«Добавить поле»**.
3. Выберите поле из ранее созданных.
4. Отметьте **«Обязательное»**, если поле должно быть заполнено при добавлении каждого предмета.
5. Сохраните.

Можно добавить сколько угодно полей и расставить галочки «обязательное» по своему усмотрению.

### Удаление типа коллекции

- Нажмите на корзину рядом с типом.
- Удаление типа не удаляет ваши коллекции — только шаблон.

## 4. Мои коллекции

Коллекция — это ваш личный экземпляр типа. Например, тип «Монеты» — общий шаблон, а «Моя коллекция монет СССР» — ваша личная коллекция.

**Страница:** `/my-collections` → **«Мои коллекции»** в навигации.

### Создание коллекции

1. Перейдите в **«Мои коллекции»**.
2. Нажмите **«Создать коллекцию»**.
3. Выберите:
   - **Тип коллекции** — шаблон из ранее созданных
   - **Название** — ваше название (например «Монеты 1960-х»)
4. Сохраните.

### Поиск коллекции

На странице «Мои коллекции» есть строка поиска — введите часть названия, список отфильтруется.

### Переименование и удаление

- **Переименовать** — нажмите на карандаш рядом с названием коллекции.
- **Удалить** — нажмите на корзину. Удалятся все предметы внутри.

## 5. Предметы коллекции

Предмет — конкретный экспонат внутри коллекции (монета, марка, пластинка и т.д.).

**Страница:** `/my-collections/:id` — открывается при клике на коллекцию.

### Добавление предмета

1. Откройте нужную коллекцию.
2. Нажмите **«Добавить элемент»**.
3. Заполните появившуюся форму:
   - **Название** — обязательно (например «1 копейка 1961 года»)
   - **Поля** — заполните все нужные поля (строка, число, дата и т.д.)
   - **Фото** — прикрепите одно или несколько фото предмета (необязательно)
4. Нажмите **«Сохранить»**.

### Редактирование предмета

1. Кликните на строку предмета в таблице — появится форма редактирования прямо под строкой.
2. Измените нужные поля.
3. Нажмите **«Сохранить»**.

### Фотографии

- К каждому предмету можно прикрепить несколько фотографий.
- Нажмите на фото в таблице — откроется лайтбокс (галерея) для просмотра.
- Число в углу миниатюры показывает, сколько всего фото у предмета.
- В режиме редактирования можно добавить новые фото и удалить существующие.

### Удаление предмета

- В режиме редактирования нажмите **«Удалить»**.

### Поиск по предметам

- Над таблицей есть строка поиска — фильтрует по названию предмета.

## 6. Просмотр коллекций других пользователей

Все коллекции на платформе открыты для просмотра.

**Страница:** `/users` → **«Пользователи»** в навигации.

### Как найти коллекцию другого пользователя

1. Перейдите в **«Пользователи»**.
2. Найдите нужного пользователя (есть поиск по имени).
3. Нажмите на карточку — откроется его профиль со списком коллекций.
4. Нажмите на коллекцию — откроется таблица с предметами.

### Поиск по предметам в чужой коллекции

На странице коллекции другого пользователя тоже есть строка поиска — фильтрует по названию предмета в реальном времени.

### Переход в свою коллекцию

Если вы вошли и открыли **собственную** коллекцию через раздел «Пользователи» — вас автоматически перенаправят на страницу управления (с кнопками добавления и редактирования).

## 7. Профиль

**Страница:** `/profile` — иконка с именем пользователя в правом верхнем углу.

### Что можно сделать в профиле

- Просмотреть свои данные (имя, фамилия, username, email, телефон)
- **Загрузить аватар** — нажмите на область с фото, выберите изображение
- **Удалить аватар** — кнопка появляется, если аватар уже загружен

Аватар отображается в хедере рядом с именем, на странице вашего профиля и в чате.

## 8. Чат и сообщения

**Страница:** `/messages` → **«Сообщения»** в навигации (доступно только после входа).

### Как начать диалог с пользователем

1. Перейдите в **«Пользователи»** и откройте профиль нужного пользователя.
2. Нажмите кнопку **«Написать»** рядом с именем.
3. Вы автоматически попадёте в чат с этим пользователем.

### Отправка текстового сообщения

1. Откройте чат (`/messages/:id`).
2. Введите текст в поле внизу.
3. Нажмите **«Отправить»** или клавишу **Enter**.

Сообщения отображаются в реальном времени — второй участник видит их мгновенно без перезагрузки страницы.

### Поделиться предметом коллекции

Можно отправить в чат ссылку на конкретный предмет коллекции:

1. Откройте коллекцию другого пользователя (`/users/:id/collections/:id`).
2. В строке нужного предмета нажмите **«Поделиться»**.
3. Вас перенаправит в чат с владельцем коллекции, а предмет автоматически отправится как сообщение.

### Карточка предмета в чате

Отправленный предмет отображается как карточка (не просто текст). Нажмите на карточку — откроется коллекция с предметом, уже найденным в строке поиска.

### Непрочитанные сообщения

- В навигации рядом с **«Сообщения»** появляется фиолетовый бейдж с числом непрочитанных.
- Счётчик обновляется в реальном времени.
- При открытии чата все сообщения автоматически помечаются как прочитанные.
- Если вы уже находитесь в открытом чате и приходит новое сообщение — счётчик не увеличивается.

### Список диалогов

На странице `/messages` отображаются все ваши диалоги:
- Имя собеседника
- Последнее сообщение (текст или «📦 название предмета»)
- Время последнего сообщения
- Число непрочитанных в этом диалоге

Нажмите на имя собеседника внутри чата — откроется его публичный профиль.

## 9. Глобальный поиск предметов

В шапке сайта есть кнопка с лупой — глобальный поиск по всем предметам всех коллекций на платформе.

### Как пользоваться

1. Нажмите на иконку лупы в правой части хедера.
2. Начните вводить название предмета — результаты появятся по мере ввода (с небольшой задержкой).
3. В выпадающем списке отображается:
   - Название предмета
   - Коллекция, в которой он находится, и имя её владельца
4. Нажмите на нужный результат — откроется страница коллекции с этим предметом, уже введённым в строку поиска.

> Поиск работает по частичному совпадению, без учёта регистра. Показывается до 15 результатов.

### Поиск доступен всем

Глобальный поиск не требует входа в систему — найти предмет может любой посетитель сайта.

## 10. Структура базы данных

### Диаграмма связей

```
users
 ├──< collection_types_entity (created_by → users.id)
 ├──< fields_entity (created_by → users.id)
 ├──< user_collections_entity (user_id → users.id)
 ├──< chats (user1_id → users.id)
 ├──< chats (user2_id → users.id)
 └──< messages (sender_id → users.id)

collection_types_entity
 ├──< collection_type_fields_entity (collection_type_id)
 └──< user_collections_entity (collection_type_id)

fields_entity
 ├──< collection_type_fields_entity (field_id)
 └──< collection_item_values_entity (field_id)

user_collections_entity
 └──< collection_items_entity (user_collection_id)

collection_items_entity
 └──< collection_item_values_entity (collection_item_id)

chats
 └──< messages (chat_id)
```

---

### Таблицы

#### `users`

| Колонка | Тип | Описание |
|---------|-----|----------|
| `id` | int PK | Первичный ключ |
| `username` | varchar UNIQUE | Имя пользователя |
| `password` | varchar | Хэш пароля (bcrypt) |
| `firstName` | varchar | Имя |
| `lastName` | varchar | Фамилия |
| `email` | varchar UNIQUE | Email |
| `phone` | varchar NULL | Телефон |
| `avatar` | varchar NULL | Имя файла аватара (хранится в `/uploads`) |

---

#### `fields_entity`

Глобальный справочник полей. Создаётся один раз, используется в любом типе коллекции.

| Колонка | Тип | Описание |
|---------|-----|----------|
| `id` | int PK | |
| `name` | varchar UNIQUE | Название поля |
| `description` | varchar | Описание |
| `field_type` | varchar | `string` / `number` / `date` / `select` / `boolean` |
| `options` | jsonb NULL | Варианты для типа `select` |
| `created_by` | int FK → users | Кто создал |
| `created_at` | timestamp | |

---

#### `collection_types_entity`

Шаблон коллекции (например «Монеты»).

| Колонка | Тип | Описание |
|---------|-----|----------|
| `id` | int PK | |
| `name` | varchar UNIQUE | Название типа |
| `description` | varchar | Описание |
| `created_by` | int FK → users | Кто создал |
| `created_at` | timestamp | |

---

#### `collection_type_fields_entity`

Связывает тип коллекции с полями. Уникальная пара `(collection_type_id, field_id)`.

| Колонка | Тип | Описание |
|---------|-----|----------|
| `id` | int PK | |
| `collection_type_id` | int FK → collection_types_entity | |
| `field_id` | int FK → fields_entity | |
| `is_required` | boolean NULL | Обязательное ли поле |

---

#### `user_collections_entity`

Личная коллекция пользователя — экземпляр типа. Уникальная тройка `(collection_type_id, user_id, name)`.

| Колонка | Тип | Описание |
|---------|-----|----------|
| `id` | int PK | |
| `name` | varchar | Название коллекции |
| `user_id` | int FK → users | Владелец |
| `collection_type_id` | int FK → collection_types_entity | Используемый шаблон |
| `created_at` | timestamp | |

---

#### `collection_items_entity`

Конкретный предмет внутри коллекции (монета, марка и т.д.).

| Колонка | Тип | Описание |
|---------|-----|----------|
| `id` | int PK | |
| `name` | varchar | Название предмета |
| `user_collection_id` | int FK → user_collections_entity | К какой коллекции относится |
| `photos` | simple-array NULL | Список имён файлов фотографий |
| `created_at` | timestamp | |

---

#### `collection_item_values_entity`

Значение одного поля для одного предмета. Одна строка = одно поле одного предмета.

| Колонка | Тип | Описание |
|---------|-----|----------|
| `id` | int PK | |
| `collection_item_id` | int FK → collection_items_entity | |
| `field_id` | int FK → fields_entity | Какое поле |
| `value` | jsonb NULL | Значение поля (любой тип — число, строка, дата, булево) |

> Значение хранится в `jsonb` — один тип для всех видов данных. Тип интерпретируется на основе `fields_entity.field_type`.

---

#### `chats`

Диалог между двумя пользователями. Создаётся один раз для пары.

| Колонка | Тип | Описание |
|---------|-----|----------|
| `id` | int PK | |
| `user1_id` | int FK → users | Первый участник |
| `user2_id` | int FK → users | Второй участник |
| `created_at` | timestamp | |

---

#### `messages`

Сообщения внутри чата.

| Колонка | Тип | Описание |
|---------|-----|----------|
| `id` | int PK | |
| `chat_id` | int FK → chats | К какому чату |
| `sender_id` | int FK → users | Отправитель |
| `content` | text | Текст сообщения (для `item` — название предмета) |
| `type` | varchar | `text` — обычное, `item` — карточка предмета |
| `item_id` | int NULL | ID предмета (`collection_items_entity`) |
| `collection_id` | int NULL | ID коллекции (`user_collections_entity`) |
| `item_owner_id` | int NULL | ID владельца коллекции (для построения URL) |
| `item_name` | varchar NULL | Название предмета (для отображения и поиска) |
| `is_read` | boolean | Прочитано ли получателем |
| `created_at` | timestamp | |
